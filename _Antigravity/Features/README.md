# 📋 THƯ MỤC TÍNH NĂNG & TASK CHECKLIST (FEATURES)

Mỗi khi bắt đầu triển khai một tính năng mới trong lộ trình (Roadmap), Tech Lead (Antigravity) sẽ tạo một file đặc tả kỹ thuật và danh sách công việc (Task Checklist) tương ứng tại đây.

## Cấu trúc 1 file Feature:
1. **Mục tiêu tính năng:** Người chơi làm được gì? Trải nghiệm ra sao?
2. **Kiến trúc & Interface:** Các class/struct cần tạo, sơ đồ gọi hàm.
3. **Skeleton Code:** File code mẫu đã định hình sẵn cấu trúc.
4. **Các bước Sếp thực hiện (Step-by-step):** Từng bước Sếp mở Unity, code gì, test ra sao.
5. **Tiêu chí hoàn thành (Definition of Done):** Điều kiện để tính năng đạt chuẩn và commit lên Git.
